C. Hooks & Automations Twenty hooks · Two notifications
  • PreToolUse · Bash check-secret-exposure.js Screens outgoing shell commands for accidental credential exposure before they run.
  • PreToolUse · Bash block-dangerous-bash.js Rejects destructive shell patterns that are too risky for normal coding sessions.
  • PreToolUse · Write/Edit protect-firmware.js Protects firmware surfaces from casual edits when the session scope is not explicitly hardware-facing.
  • PreToolUse · Obsidian block-obsidian-delete.js Stops destructive note deletion inside Obsidian-linked workspaces.
  • PostToolUse · Write/Edit format-on-edit.js Runs targeted formatting after file writes so touched files stay clean without a full-repo pass.
  • Stop check-session-size.js Warns when a session is getting too large to remain efficient and easy to reason about.
  • SessionStart session-primer.js Injects startup context so each session begins with the current workspace rules and constraints in view.
  • PreToolUse · Bash/WebFetch block-egress-exfil.js Blocks outbound requests to suspicious destinations — prevents data exfiltration via curl, fetch, or webhook calls.
  • PreToolUse · Write/Edit protect-security-config.js Guards security-critical config files (hooks, settings.json, .gitignore) from casual edits that could silently weaken the protection stack.
  • PreToolUse · Write scan-write-for-secrets.js Scans file content being written for API keys, tokens, and credential patterns before the write lands on disk.
  • PreToolUse · Read block-sensitive-file-read.js Blocks reads of sensitive paths (26_Sensitive/, AI Reference.md, .env files, .ssh/) to enforce vault and credential guardrails.
  • PreToolUse · WebFetch block-nasa-web-egress.js Restricts outbound web fetches during sessions scoped to NASA-adjacent research work.
  • PostToolUse · Bash auto-schedule-codex-poll.js After Codex background tasks are dispatched, auto-schedules a wakeup poll so results are retrieved without manual follow-up.
  • PostToolUse · Bash scan-output-for-secrets.js Screens shell command output for credentials or tokens before they appear in the conversation context.
  • PostToolUse · Bash audit-bash-log.js Logs every shell command executed by Claude for post-session review — lightweight audit trail.
  • UserPromptSubmit task-state-reminder.js On every user message, reminds Claude to update the session task-state file — keeps CURRENT-TASK.md in sync across compactions.
  • Stop stop-toast-gate.js Shows a toast notification when Claude finishes a turn, giving a visual signal without requiring the terminal to stay in focus.
  • Stop double-shot-latte.js Stop hook for custom end-of-turn behavior (personal automation).
  • PreToolUse · Read/Grep/Glob protect-ai-reference.js Hard-blocks access to AI Reference.md and the 26_Sensitive vault folder across all read-type tools and Obsidian MCP.
  • PostToolUse · Write/Edit scrub-secrets-from-output.js Scrubs known secret patterns from tool output before they reach conversation context. (Available; not currently wired.)
  • Notification Windows popup · attention needed Pops a 5-second Windows dialog when Claude needs user input — useful when the terminal is backgrounded.
  • Notification Windows popup · agent complete Plays a system sound and pops a persistent dialog when a Codex or background agent finishes, with the agent's completion message.

V Workflow Library When to use what

A decision map across the tools, skills, hooks, and memory rules I have installed — grouped by what I'm trying to do. The full catalog lives in Claude Research Folder/claude-toolkit-map.md; this is the "what do I reach for" view.

  • A Review code

    When something needs a second pass before merge

    Quick PR review → /review or /codex:review on the staged diff. Deep pre-merge review → /walmart-ultrareview main...HEAD from the repo root (worktree sandbox + live render + verification pass; auto-deep-mode for ≥4 files). Adversarial / pre-refactor scan → /codex:adversarial-review. Security check → /security-review. Whole-project audit → /doctor (46 checks, auto-detects maturity) or /tech-debt-audit.

  • B Build something new

    First drafts, scaffolds, and starters

    New repo / CLAUDE.md scaffold → /init. Single-file Express + Vercel + dark/light scaffold → copy site-runtime-baseline/. Knowledge-graph SPA → /build-graph-explorer (~5.6k-line reference impl). Deadline / application tracker → /build-tracker (calendar + cards + table + map + iCal). Field-mapping site from a corpus → /map-field. Design system from scratch → /hue (also Codex-compatible). Bulk codegen ≥200 lines from a tight brief → Codex via /codex:rescue.

  • C Solve a problem

    Bugs, debugging, things that broke

    Debug round 1 → Sonnet. Read the error, read the code, propose fix. Debug round 2 (already failed once) → escalate to Opus subagent — the failure looks like "didn't think hard enough," not "bad brief." Long autonomous investigation → Codex with --background; pair with ScheduleWakeup(180s) polling. Visual UI bug → Playwright at desktop AND mobile; per feedback_visual_ui_check.md, screenshot before declaring done. Tech-debt cleanup → /tech-debt-audit first; apply findings same-session if scoped tight. "Claude is going in circles" → ask for the diff and which line addresses what; force the verification path.

  • D Research

    Find things, synthesize, write

    Multi-step web research → /deep-search (query fan-out + practitioner sources + inline citations). Process LinkedIn inbox → /process-linkedin-inbox. Crawl an entire site → Firecrawl MCP. Semantic search → Exa MCP (paired with Firecrawl for full content). Fellowship draft critique → /fellowship-review. Daily / weekly reflection → /daily-review.

  • E Session & state

    Keep work durable across sessions

    Long task spanning compactions → write CURRENT-TASK.md first; the task-state-reminder.js hook fires on every message. End of long session → ~/bin/rollover-session.ps1. Background agents / Codex → write to BACKGROUND-TASKS.md immediately after dispatch (per feedback_background_agent_tracking.md). Capture a reusable pattern after a task → /make-playbook. Recurring task → /loop <interval> <cmd> or /schedule for cron. Multi-part independent work → /parallelize.

  • F Documents & files

    Slides, PDFs, Word, Excel, posters

    Slides / decks → anthropic-skills:pptx. PDFs (read, fill, sign, merge) → anthropic-skills:pdf + pdf-viewer:*. Word documents (reports, memos, letters) → anthropic-skills:docx. Spreadsheets (.xlsx, .csv, .tsv) → anthropic-skills:xlsx. Posters / static art → anthropic-skills:canvas-design. Themed claude.ai HTML artifacts → anthropic-skills:web-artifacts-builder + theme-factory.

  • G Model picking

    Which model when

    Inventory / glob sweep / status → Haiku (cheap, fast, no reasoning needed). Routine implementation, single-feature change → Sonnet (default). Architectural decision, hard-to-reverse refactor, debug round 2 → Opus. Greenfield codegen ≥200 lines from tight brief, long single-file refactor, mechanical bulk edits → Codex (GPT-5.4 / 5.5) — beats Opus for code-shaped work. Brief-writing itself → always chat-side (Opus or Sonnet); never delegate the brief.

  • H Safety & verification

    Don't ship a wrong-repo or bad-credential change

    Before any commit/push → git remote -v + git branch --show-current; quote them back. Per feedback_repo_verification_before_commit.md; consult repo-map.md. Before writing a credential file → put it in ~/.config/<project>/, verify with git check-ignore. Per feedback_credential_storage.md. After any UI change → screenshot at desktop AND mobile; check overlap, contrast, clipping. Per feedback_visual_ui_check.md. Long voice prompt with 5+ items → write every item verbatim to CURRENT-TASK.md before code. Per feedback_long_prompt_discipline.md.
