I Research Ten works

Papers, reference libraries, and interactive tools from ongoing work in design-for-manufacturing, AI, and human–AI collaboration.

  • 01 Paper

    IDETC Paper Site

    idetc-paper-site.vercel.app

    Companion web version of the ASME IDETC 2026 paper on capturing tacit design-for-manufacturing knowledge from unstructured discourse. With hoverable glossary, numbered citations, and collapsible appendices.

    Live ↗ Source
  • 02 Essay

    The Web Looks the Way Someone Chose

    web-design-guide-lilac.vercel.app

    A field guide on why vibe-coded sites look generic, and what designers actually do. Maps 14 visual vocabularies and 30 living design traditions.

    Live ↗ Source
  • 03 Reference

    Ways of Thinking

    viz-research-hub.vercel.app

    A reference library for interactive ideas. Fourteen sections spanning explorable explanations, reactive documents, knowledge graphs, embedding spaces, simulations, and data art — with ~200 linked sources.

    Live ↗ Source
  • 04 Interactive · React

    AI Industry Map — Explorer

    ai-industry-map-explorer.vercel.app

    Zoomable cluster map of the generative-AI tool ecosystem. D3 force layout with a starfield background — the interactive companion to the static map.

    Live ↗ Source
  • 05 Catalog

    AI Industry Map

    ai-industry-map.vercel.app

    Static multi-page guide to the generative-AI tooling ecosystem, organized by what each tool does — LLM providers, code editors, agent frameworks, vector DBs, and more.

    Live ↗ Source
  • 06 Reference · Map

    AI Schools of Thought

    ai-schools-of-thought-explorer.vercel.app

    A living map of the competing ideas in AI — not the products, but the arguments. Three levels: topic → school → voice, with cited sources. Sister site to the AI Industry Map.

    Live ↗ Source
  • 07 Reference · Serverless

    Paper Terminology Hub

    terminology-site.vercel.app

    Personal reference for words, methods, and ideas drawn from research papers. Tag-filtered grid with per-term pages. New submissions route through an OpenAI-powered serverless function.

    Live ↗ Source
  • 08 Hub

    Research Hub

    dpm-research-hub.vercel.app

    Curated summaries of talks, papers, and ideas across AI, design, and ML — human–AI collaboration, weight-space learning, DeCoDe Lab work. Includes a sandbox for the Psych_Battery e-ink project.

    Live ↗ Source TBD
  • 09 Interactive · Map

    DFM Graph Explorer

    dfm-graph-explorer.vercel.app

    Engineering discussion field map — an interactive graph over design-for-manufacturing discourse. Visualizes how topics, terms, and sources connect across the corpus.

    Live ↗ Source
  • 10 Agent

    DFM · Knowledge Graph Agent

    dfm-kg-agent-v2.vercel.app

    Agent interface for querying and extending the DFM knowledge graph. Pairs with the graph explorer — one for navigating, one for reasoning over the same underlying structure.

    Live ↗ Source
